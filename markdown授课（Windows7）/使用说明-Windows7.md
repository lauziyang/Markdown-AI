# Markdown 精讲 · 交互式学习网站（Windows 7 免安装版）

> 本文件夹是网站的 **Windows 7 适配版**：整个网站（6 大模块、26 课、全部交互功能）被打包进
> **一个 HTML 文件**，双击即可使用，**不需要安装任何软件、不需要 Node.js、不需要 Python、不需要联网**。

---

## 一、如何使用（在 Windows 7 上）

**方法 1（推荐）**：双击 `启动网站.bat` → 自动用默认浏览器打开网站。

**方法 2**：直接双击 `site\dist\index.html`。

**方法 3**：打开浏览器（见下方浏览器要求），把 `index.html` 拖进窗口。

打开后即可正常学习：章节导航、双栏实时编辑器、闯关练习、Mermaid 图表、公式、小测验……全部可用。

> 学习进度、徽章、连续学习天数保存在**浏览器本地**（localStorage），关闭后再次打开会保留；
> 换浏览器或换电脑会重新开始。网站自带「🗑️ 重置进度」按钮（侧边栏左下角）。

---

## 二、浏览器要求（重要）

Windows 7 官方已停止支持，新版浏览器无法安装，请使用以下任一版本：

| 浏览器 | 推荐版本 | 说明 |
| ------ | -------- | ---- |
| **Chrome** | **109**（Win7 支持的最后一个版本） | 功能完整，最推荐 |
| **Firefox** | **115 ESR**（最后支持 Win7 的版本） | 可用 |
| **Edge** | **109**（Chromium 内核，最后支持 Win7） | 可用 |

> ❌ 不支持 IE 11 及更早版本（不支持现代 JS 语法）。
> 下载地址：`https://dl.google.com/chrome/` 选旧版本，或搜索「Chrome 109 离线安装包」。

## 四、如何移植到 Windows 7

1. 把整个 `markdown授课（Windows7）` 文件夹复制到 U 盘 / 移动硬盘（约 700 KB 源码 + 7.5 MB 成品）。
2. 在 Windows 7 电脑上，把文件夹拷到任意位置（桌面、D 盘均可，**路径建议不要有特殊符号**）。
3. 双击 `启动网站.bat` 或 `site\dist\index.html` 即可使用。

整个过程**不需要联网、不需要安装任何软件**。

---

## 五、如何修改内容 / 重新构建

改内容需要一台装有 **Node.js 18+** 的电脑（现代 Windows / Mac / Linux 均可，Win7 上不用装）。

```bash
cd site
npm install          # 首次需要，安装依赖
npm run dev          # 开发模式：实时预览修改效果
npm run build:win7   # 打包成单文件：生成新的 site/dist/index.html
```

修改页面文字/样式/题目：编辑 `site/src/pages/` 下对应文件（如 `learn/advanced/quiz.jsx` 是测验）后重新构建即可。
构建产物 `dist/index.html` 拷回 Win7 电脑就能用。

> 本文件夹的源码是「单文件版」配置（`vite.config.js` 用了 `vite-plugin-singlefile`），
> 与原始项目（`markdown授课/site`）互相独立，互不影响。

## 六、常见问题

**Q：双击后浏览器没反应 / 白屏？**
浏览器太老（IE 等）。请换用 Chrome 109 或 Firefox 115 ESR。
首次打开 7.5MB 的单文件，加载需要几秒，请耐心等待。

**Q：可以放到服务器上给多人访问吗？**
可以。`dist/index.html` 是纯静态文件，放进任意 Web 服务器（或学校机房共享目录）就能被多人打开；
不过多人共用一台电脑时进度是共用的（都存在浏览器里）。

**Q：杀毒软件提示？**
单文件 HTML 是纯网页，无任何可执行代码，一般不会误报；如提示请选择「信任」。

**Q：换了浏览器，进度没了？**
进度存在浏览器 localStorage 里，换浏览器/清除浏览器数据会清空。可用侧边栏「🗑️ 重置进度」重新开始。
