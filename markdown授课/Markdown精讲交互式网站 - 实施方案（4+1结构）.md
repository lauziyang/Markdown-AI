## 模块一：初识Markdown（50min）

### 学习目标
理解Markdown的价值，搭建写作环境

### 交互设计

**1. 对比展示（开场抓注意力）**
```
┌────────────────────────────────────────────────────┐
│  同一份文档，两种写作方式                          │
│  ┌───────────────┐  ┌───────────────┐            │
│  │ 📝 Word方式   │  │ ✨ Markdown   │            │
│  │ 鼠标点来点去  │  │ 纯文本写作    │            │
│  │ 格式刷来刷去  │  │ 一次成型      │            │
│  │ 保存总担心乱码│  │ 版本友好      │            │
│  └───────────────┘  └───────────────┘            │
│  [点击体验] 用两种方式写同一段文字                 │
└────────────────────────────────────────────────────┘
```
- 左右分屏，左侧模拟Word操作（点按钮设置格式），右侧用Markdown语法
- 让用户直观感受Markdown的高效

**2. 一分钟上手（第一个互动）**
- 页面中央就是一个编辑器
- 预设引导："试试输入 # 然后空格，打'我的第一篇Markdown'"
- 实时预览区同步显示
- 完成即获得✨第一个成就

**3. 环境配置向导**
- 步骤化引导：VS Code安装 → Markdown插件推荐 → 预览快捷键
- 每个步骤配有动图演示
- 提供在线编辑器（无需安装，直接开练）

**4. 小练习：写一段自我介绍**
- 要求：标题 + 一段文字 + 一个链接
- 系统自动检测是否包含这三个要素
- 通过后解锁下一模块

### 关键页面
`/learn/intro` - Markdown是什么  
`/learn/setup` - 环境配置  
`/learn/first` - 第一个文档

## 模块二：核心语法精讲（60min）

### 学习目标
掌握Markdown最常用的10个语法，覆盖日常写作80%场景

### 交互设计

**1. 语法卡片矩阵（主交互方式）**

每个语法一张卡片，点击展开详细讲解 + 即时练习

| 语法      | 讲解方式              | 练习形式           |
| --------- | --------------------- | ------------------ |
| 标题      | 动画演示#数量对应层级 | 输入正确层级的标题 |
| 加粗/斜体 | 高亮显示包裹符号      | 把普通文字改成加粗 |
| 删除线    | 对比效果              | 给文字加删除线     |
| 有序列表  | 自动编号演示          | 写一个3步操作步骤  |
| 无序列表  | 符号切换演示          | 写一个购物清单     |
| 链接      | 分步拆解 [文字](url)  | 给文字加超链接     |
| 图片      | 对比![]与[]的区别     | 插入一张图片       |
| 引用      | 嵌套层级动画          | 写一段嵌套引用     |
| 分割线    | 三种写法演示          | 插入一条分割线     |
| 换行      | 常见错误演示          | 正确换行两次       |

**2. 闯关模式（核心驱动力）**
```
关卡1: 标题         ████████░░ 80%   ⭐ 已完成
关卡2: 强调         ██████░░░░ 60%   🔓 进行中
关卡3: 列表         ░░░░░░░░░░ 0%    🔒 未解锁
关卡4: 链接与图片    ░░░░░░░░░░ 0%    🔒 未解锁
...
```
- 每关3-5个小任务
- 实时检测语法正确性
- 全部通关获得"语法大师"徽章

**3. 常见错误对照（视觉化）**
```
❌ 错误写法              ✅ 正确写法
#标题（缺少空格）   →    # 标题（有空格）
**文字（缺少闭合）  →    **文字**（完整闭合）
- 列表（缩进不对）  →      - 列表（标准缩进）
```
- 点击可切换显示错误原因
- 用户可拖拽匹配错误与正确写法

**4. 综合练习：格式化一段混乱文本**
- 给出一段没有任何格式的纯文本
- 用户用Markdown给它加上标题、列表、强调等
- 对比参考答案

### 关键页面
`/learn/core/headings` - 标题专题  
`/learn/core/emphasis` - 强调专题  
`/learn/core/lists` - 列表专题  
`/learn/core/links` - 链接专题  
`/learn/core/playground` - 综合练习场

- 点击"显示答案"对比

**5. 小测验：10道选择题**
- 覆盖进阶语法易错点

## 模块四：高级应用（60min）

### 学习目标
用Markdown画图、写公式、做目录、混写HTML

### 交互设计

**1. Mermaid图表工坊（重点）**
```
左侧：Mermaid代码         右侧：实时图表
graph TD                    ┌──────┐
  A[开始] --> B[处理]       │ 开始 │
  B --> C{判断}             └──┬───┘
  C -->|是| D[结束]            ↓
                              ┌──────┐
                              │ 处理 │
                              └──┬───┘
                                  ↓
                              ┌──┴───┐
                              │ 判断 │
                              └──┬───┘
                                  ↓
                              是   ↓
                              ┌──────┐
                              │ 结束 │
                              └──────┘
```
**功能：**
- 预设模板：流程图/时序图/类图/状态图/甘特图
- 一键插入模板，修改即更新
- 颜色主题切换
- 导出为PNG/SVG

**练习任务：** 用流程图描述"早上起床到出门"的过程

**2. LaTeX公式编辑器**
- 常用公式模板：分数、根号、积分、矩阵、方程组
- 点击模板插入，自动生成LaTeX代码
- 实时渲染显示
- 支持复制公式图片

**3. HTML混写演示**
- 展示Markdown中嵌入HTML的效果
- 示例：自定义颜色文字、调整图片大小、嵌入视频
- 用户尝试修改HTML属性看效果变化

**4. 自动生成目录（TOC）**
- 输入一篇长文档，点击"生成目录"
- 动画演示TOC如何从标题中提取
- 对比有/无TOC的阅读体验
- 支持多级目录缩进

**5. 综合挑战：写一份技术方案文档**
要求包含：
- 标题层级（至少3级）
- 表格（对比方案）
- 流程图（架构图）
- 代码块（示例代码）
- 公式（如有需要）

### 关键页面
`/learn/advanced/mermaid` - Mermaid图表  
`/learn/advanced/latex` - 公式编辑  
`/learn/advanced/html` - HTML混写  
`/learn/advanced/toc` - 目录生成
