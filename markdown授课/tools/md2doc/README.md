# 📁 tools/md2doc —— Markdown 转公文小程序

此目录用于存放「Markdown 转公文」小程序的 **exe 文件**。

## 使用说明

1. 由老师提供 exe 文件后，直接放到本目录：
   ```
   tools/md2doc/
   ├── README.md          ← 本文件
   └── md2doc.exe         ← 老师提供的程序（放到这里）
   ```
2. 双击运行即可把 Markdown 文档转换为公文格式（Word/PDF）。

## 与教学网站的关系

在「模块六 · AI 辅助」页面中有一个入口，引导学员到这里获取该小程序。
对应源代码位于：`site/src/pages/learn/ai/assistant.jsx`。
